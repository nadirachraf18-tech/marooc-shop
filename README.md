# MAROOC.SHOP

Landing page responsive pour le Smart Laundry Cup.

- Prix : 249 DH
- Livraison : offerte
- Paiement : à la réception (COD)
- WhatsApp : +212 656 219 486

## Déploiement sur Vercel
1. Importer ce dépôt GitHub dans Vercel.
2. Framework preset : Other (site HTML/CSS/JS statique).
3. Build command : laisser vide.
4. Output directory : laisser vide / racine du projet.
5. Déployer.

Chaque push sur la branche main déclenchera un nouveau déploiement si le dépôt est connecté au projet Vercel.

## Modifier le produit
- Modifier les textes et sections dans `index.html`.
- Modifier les styles dans `styles.css`.
- Modifier le prix et le numéro WhatsApp dans `script.js`.

## Important
L'illustration CSS du produit est provisoire et ne remplace pas une photo réelle du modèle exact. Remplacer l'illustration par les photos originales du produit avant les campagnes publicitaires.

Le formulaire ouvre WhatsApp avec les informations saisies. Il ne stocke pas les commandes dans une base de données et une commande n'est confirmée qu'après l'envoi du message par le client.
